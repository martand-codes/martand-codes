## 📐 Engineering Principles

1. **Failure Modes Over Happy Paths:** Account for race conditions, network failures, and external API errors.
2. **Verify Behavior, Don't Assume:** Reproduce failures and validate fixes with tests.
3. **Document Root Causes:** Preserve investigation findings, resolutions, and regression-prevention measures.
4. **Architectural Clarity:** Make trade-offs explicit and keep components decoupled where it adds value.
