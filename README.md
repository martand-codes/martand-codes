## 📐 Engineering Principles

1. **Failure Modes Over Happy Paths**: Design systems anticipating network dropouts, race conditions, and external API timeouts.
2. **Verify Behavior, Don't Assume**: Reproduce bugs at the execution boundary rather than guessing.
3. **Document Root Causes**: Immutable post-mortems and regression prevention over quick, uninspected patches.
4. **Architectural Clarity**: Prefer explicit trade-offs and decoupled components over unnecessary complexity.
